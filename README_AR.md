# Exam Planner – Omar

تطبيق Android لتنظيم المواد والامتحانات وجلسات المذاكرة.

## المزايا في الإصدار الحالي من الكود
- إضافة المواد وتاريخ الامتحان.
- عدّ تنازلي للامتحان القادم ولكل مادة (يدعم YYYY-MM-DD و dd/MM/yyyy و dd/MM).
- إضافة جلسات مذاكرة بتاريخ ووقت بداية ونهاية.
- تنبيه محلي عند بداية جلسة المذاكرة (قد تتطلب بعض أجهزة Android السماح بالإشعارات وتشغيل التنبيهات في الخلفية).
- إضافة محاضرات ومهام لكل مادة، وتحديد المنجز وحساب نسبة التقدم.
- حفظ البيانات محلياً على الجهاز.

## بناء APK
افتح المشروع في Android Studio، انتظر Gradle Sync، ثم اختر:
Build > Build Bundle(s) / APK(s) > Build APK(s)

## البناء عبر GitHub Actions
ارفع محتويات المشروع إلى مستودع GitHub، ثم افتح Actions وشغّل workflow باسم Build Android APK. نزّل Artifact باسم ExamPlanner-debug-apk وفك ضغطه للحصول على APK.

ملاحظة: هذه نسخة تجريبية أولية وليست منشورة على Google Play. يجب اختبار الإشعارات على جهازك، لأن سياسات توفير البطارية تختلف بين الشركات.
